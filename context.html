F1 Team Radio AI Telemetry & Sentiment Analyzer · Context Map for AI Coding Agents

Project Overview

Silent Co-Driver is an F1 team-radio sentiment & telemetry correlation tool built for a Hugging Face hackathon.

  • Input: Driver team radio audio (.wav / .mp3) + metadata.
  • Transcription: openai/whisper-small running in-process via Hugging Face transformers.
  • Emotion Analysis: ehcalabres/wav2vec2-lg-xlsr-en-speech-emotion-recognition mapped to calm, stressed, tired.
  • Telemetry Correlation: OpenF1 REST API (api.openf1.org/v1) 3-step lookup chain matching exact lap times or fallbacks.

Hard Rules (Locked Guidelines)

  1. No Live HF Inference APIs: Both Whisper and wav2vec2 models MUST run in-process inside FastAPI at startup.
  2. No Fabricated Lap Data: If OpenF1 correlation fails, display "no lap data" — NEVER interpolate or guess a number.
  3. Strict Pit-Wall Design System: Palette is strictly locked to `#0D1117` base, `#161B22` panel, `#2A313C` border, and F1 sector timing colors (`#9D4EDD`, `#00D268`, `#FFD93D`, `#E10600`).
  4. No Fuzzy Driver Matching: `racing_number` validates directly against OpenF1 `/v1/drivers`.

API Endpoint Contract

POST /analyze (Multipart Form Data)

Field Type Description
fileFile.wav or .mp3 audio file
driver_idstringDriver identifier (e.g. "verstappen")
racing_numberintDriver number (e.g. 1, 16, 44)
grand_prixstringCircuit/GP name (e.g. "Monaco")
session_datestringSession date ISO (YYYY-MM-DD)
message_timestampstringRadio message timestamp ISO

JSON Response Schema

{
  "transcript": "Box box box for soft tires",
  "emotion": {
    "raw_label": "angry",
    "score": 0.9412,
    "bucket": "stressed" // calm | stressed | tired
  },
  "lap": {
    "lap_number": 42,
    "lap_duration": 74.521,
    "method": "exact", // exact | fallback_early | fallback_mid | fallback_late | error
    "driver_mean": 75.120,
    "session_mean": 75.890,
    "error": null
  }
}

5. How to Run & Verify

# 1. Start FastAPI Backend (runs on port 8000)
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --port 8000

# 2. Start Next.js Frontend (runs on port 3000)
cd frontend
npm run dev

# 3. Verify Health Endpoint
curl http://localhost:8000/health
# Output: {"status":"ok","version":"0.1.0"}
